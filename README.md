# Human Essence Labs — Website

Enterprise-grade AI systems company website built with modern web technologies.

## Tech Stack

- **React 19** + TypeScript
- **Tailwind CSS 4** with custom design tokens
- **Framer Motion** for animations
- **Vite** for development and build
- **shadcn/ui** component library

## Design

"Command Center Noir" — A dark, enterprise-grade aesthetic inspired by mission control interfaces. Features glassmorphism cards, animated counters, gradient text effects, and a monospace data-label system.

## Getting Started

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
